  • /01

    TRMS AI Chatbot — Training Resource Management System

    An enterprise AI assistant built on a RAG (Retrieval-Augmented Generation) architecture. Connects a FastAPI backend to a vector store, enabling employees to query training data, generate reports, and surface structured insights using natural language.

    The system implements role-based access control, ensuring each user only retrieves data relevant to their office and permission level. Query routing detects intent and selects the appropriate retrieval path — vector similarity for semantic queries, direct SQL for structured lookups. LLM output is grounded strictly in retrieved context, minimizing hallucination risk. PDF report generation is available on-demand.

    FastAPI · RAG · ChromaDB · LLM Orchestration · Role-Based Access · SQL · PDF Generation · Intent Detection

  • /02

    IRISSET AI Chatbot — Intelligent Website Assistant

    A web-crawling AI assistant that indexes live website content and serves it through a conversational interface. The crawler parses HTML content, extracts structured information, and indexes it using TF-IDF lexical retrieval combined with semantic similarity scoring.

    Designed for organizations that need their website content to be instantly searchable via natural language. The architecture uses dynamic API routing to serve the most relevant content chunks to the LLM context window, keeping responses accurate and grounded in current published information.

    Web Crawling · TF-IDF · Lexical Retrieval · LLM · Dynamic API Routing · Content Parsing · Python

  • /03

    The Autonomous Analyst — AI-Powered Data Reasoning System

    An analytical system that combines autonomous reasoning with structured data retrieval. Rather than treating the LLM as a database, the system separates retrieval from reasoning — the model receives precisely curated context from which it performs structured analysis and surfaces actionable insights.

    Architecture prioritizes deterministic retrieval: queries are parsed for intent, mapped to data sources, and validated before the LLM generates a response. This approach reduces hallucination and makes the system's outputs auditable and trustworthy for business-critical decisions.

    Autonomous AI · Data Retrieval · Reasoning Pipelines · Backend Architecture · FastAPI · Structured Analysis

  • /04

    NEXUS Data Core — Intelligent Data Orchestration Layer

    A high-throughput data system designed to connect AI orchestration with structured enterprise data sources. Built to handle concurrent queries while maintaining strict data access boundaries — no data leaks across context boundaries, no unvalidated writes.

    The architecture decouples ingestion, routing, and retrieval. Incoming requests are classified by type, routed to the appropriate data layer (vector store for semantic, SQL for structured), and returned with provenance metadata. The system is designed to be extended with new data sources without rewriting the orchestration layer.

    Data Orchestration · AI Integration · SQL · Vector Retrieval · Microservices · Scalable Architecture

  • /05

    WASM RAG — Browser-Side Vector Search Experiment

    An experimental project testing the feasibility of running vector similarity search directly inside a browser using WebAssembly. The core question: can meaningful retrieval happen client-side, eliminating server round-trips for small-to-medium knowledge bases?

    The experiment compiles retrieval logic to WASM, embeds document vectors in the browser context, and runs cosine similarity search locally. Latency measurements reveal where client-side retrieval is viable and where server infrastructure remains necessary. This work directly informs architectural decisions in larger RAG systems.

    WebAssembly · Vector Search · RAG · Browser Performance · Retrieval Architecture · Experimentation

  • /06

    ERPNext Custom Modules — Enterprise Workflow Engineering

    Custom Frappe/ERPNext module development for real operational businesses. Work covers inventory management automation, stock entry processing, purchase and sales workflows, custom doctype creation, automated reconciliation systems, and data validation pipelines integrated with existing business logic.

    Each module is designed to reduce manual operational load — automating what was previously done by spreadsheet, replacing fragile human processes with reliable, auditable software systems. The focus is on correctness, not just functionality.

    ERPNext · Frappe · Python · Custom Doctypes · Inventory · Stock Management · Purchase · Sales Automation

  • /07

    Verdict ERP — Device & SIM Bundle Automation

    A complex ERPNext customization for a GPS tracking device business. The core challenge: devices and SIM cards must be tracked individually (by IMEI, SIM1/SIM2, ICCID) and bundled together for sales, purchase, and inventory workflows — none of which ERPNext handles natively.

    Built custom doctypes for Device-SIM Bundle management, automated stock entry creation from purchase invoices, Excel-based bulk import processing for large inventory loads, AMC and software license tracking, and sales workflow automation that maps bundles to customer accounts. Every workflow step is auditable and reversible.

    ERPNext · Frappe · IMEI Tracking · ICCID · Device-SIM Bundling · Purchase Invoice · Stock Entry · Excel Import · AMC

  • /08

    Chrome Productivity Homepage — Personal Command Center

    A custom browser new-tab experience designed to replace the default Chrome homepage with an intentional productivity interface. Focuses on reducing friction in daily workflows — fast access to frequently used tools, custom search routing, visual focus cues, and a clean aesthetic that doesn't fight for attention.

    Built with plain HTML, CSS, and JavaScript. No frameworks, no dependencies — just precise interaction design and a strong understanding that the tools engineers use every day should be as well-crafted as the systems they build.

    HTML · CSS · JavaScript · Browser Extension · Productivity · UX Design · Interaction Design
