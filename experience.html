From retrieval pipelines to enterprise automation — a journey through the systems that matter.

  • /01

    AI & LLM Engineering

    Designing and building production-grade RAG (Retrieval-Augmented Generation) systems that connect language models with real business data. Work spans intent detection, query routing, role-based access control, vector retrieval (Chroma, Qdrant), LLM orchestration, and structured SQL querying — all without hallucination-prone black-box approaches.

    FastAPI · RAG · ChromaDB · Qdrant · LLM Orchestration · Intent Detection · Role-Aware AI

    Backend & API Engineering

    Building reliable, high-performance APIs and data services using Python and FastAPI. Experience covers microservices design, SQL database architecture, data pipeline construction, event-driven patterns, and migrating legacy monolithic systems into modular, scalable backends. Focus is always on deterministic behavior, low latency, and maintainable code.

    Python · FastAPI · PostgreSQL · SQL · Microservices · REST APIs · Data Pipelines

  • /03

    ERPNext & Frappe Development

    Custom enterprise software development on the ERPNext / Frappe framework. Built custom doctypes, automated business workflows, stock entry processing, device and SIM bundle management (IMEI, ICCID tracking), purchase invoice automation, sales workflows, software license and AMC modules, and Excel-based bulk import pipelines. Real-world ERP engineering for operational businesses.

    ERPNext · Frappe · Custom Doctypes · Stock Management · Purchase Workflows · Sales Automation

  • /04

    System Architecture & Design

    Designing systems that hold up under real load. Experience includes decoupling retrieval from generation in AI pipelines, building deterministic routing layers, implementing role-based data access architectures, and designing enterprise patterns that prioritize correctness over cleverness. Complexity is treated as debt — not a feature.

    System Design · Deterministic Routing · Role-Based Access · Enterprise Patterns · Data Security

  • /05

    Full-Stack & Frontend Engineering

    Building complete, production-ready web experiences from backend to interface. Frontend work ranges from interactive parallax portfolio sites with GSAP and luxy.js, to custom browser productivity tools, to AI chatbot interfaces. The goal is always: fast, intentional, and built to last.

    HTML · CSS · JavaScript · GSAP · Luxy.js · React · Responsive Design · Performance

  • /06

    AI Research & Experimentation

    Active experimentation at the frontier of AI systems. Current areas include browser-side vector search using WebAssembly (WASM RAG), self-healing data pipelines via semantic drift detection, edge-device LLM orchestration, and role-aware retrieval architectures. Production engineering requires knowing what works — lab work is how that knowledge is built.

    WebAssembly · Vector Search · Retrieval Architecture · Edge AI · Semantic Drift · LLM Research
